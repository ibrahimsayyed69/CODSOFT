# Data Science Internship Portfolio - CodSoft

Welcome to my Data Science internship repository! This repository contains a collection of machine learning and data analysis projects developed during my internship journey at **CodSoft**. The primary goal of these projects was to solve real-world problems by working through the complete data science lifecycle—from data cleaning and exploratory data analysis (EDA) to model building, optimization, and evaluation.

---

## 🚀 Projects Overview

### 1. 📊 Titanic Survival Prediction
* **Objective:** Build a predictive model to determine whether a passenger survived the Titanic crash based on features like age, gender, socio-economic class, and cabin details.
* **Type:** Binary Classification
* **Key Techniques:** Handling missing data, categorical encoding, exploratory data analysis (EDA), and evaluating model accuracy.

### 2. 🎬 Movie Rating Prediction
* **Objective:** Analyze historical movie datasets and build a model to estimate viewer ratings based on features like genre, director, cast, and budget.
* **Type:** Regression / Predictive Modeling
* **Key Techniques:** Extracting patterns from categorical data, correlation analysis, and training regression algorithms to output continuous targets.

### 3. 🌸 Iris Flower Classification
* **Objective:** Classify iris flowers into three distinct species (Setosa, Versicolor, and Virginica) based on their sepal and petal length/width measurements.
* **Type:** Multi-class Classification
* **Key Techniques:** Data visualization using pair plots with Seaborn, pattern recognition, and evaluation metrics (accuracy, precision, recall).

### 4. 📈 Sales Prediction
* **Objective:** Forecast future product demand and sales volumes based on historical advertising spend data across various media channels (TV, Radio, Newspaper).
* **Type:** Regression Analysis
* **Key Techniques:** Simple and Multiple Linear Regression, evaluation metrics ($R^2$ Score, Mean Absolute Error, Mean Squared Error), and feature scaling.

### 5. 💳 Credit Card Fraud Detection
* **Objective:** Identify fraudulent credit card transactions from highly skewed real-world transactional data.
* **Type:** Anomaly Detection / Binary Classification
* **Key Techniques:** Dealing with highly imbalanced datasets (using sampling techniques or class-weight adjustments), precision-recall curve analysis, and model optimization.
